Cyber Macro Impact Pilot

1 Research question

How are country-level cyber readiness and incident intensity associated with macro outcomes such as GDP growth, productivity, investment, and employment?

2 Data

This report uses the processed panel at data_processed/panel_country_year.parquet.

suppressPackageStartupMessages({
    library(arrow)
    library(dplyr)
    library(knitr)
})

panel_path <- "data_processed/panel_country_year.parquet"
dict_path <- "data_processed/data_dictionary.csv"

if (!file.exists(panel_path)) {
    stop("Missing panel file. Run R/03_build_panel.R first.")
}

panel <- arrow::read_parquet(panel_path)

summary_tbl <- tibble::tibble(
    metric = c("Rows", "Countries", "Year min", "Year max"),
    value = c(
        nrow(panel),
        dplyr::n_distinct(panel$iso3c),
        min(panel$year, na.rm = TRUE),
        max(panel$year, na.rm = TRUE)
    )
)

knitr::kable(summary_tbl, caption = "Panel snapshot")
